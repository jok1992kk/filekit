# FileKit — CLAUDE.md

> Постоянный контекст проекта. Держи этот файл коротким. Детали продукта — в `SPEC.md`, пошаговые задачи — в `CODE-PROMPTS.md`.

## Продукт

SaaS для онлайн-продавцов: подготовка фотографий товаров под Amazon / Etsy / Shopify / eBay.
Позиционирование: **Upload once. Sell everywhere.**
Основной сценарий: **Upload → Select marketplace → Prepare → Download.**

Весь контент сайта — **английский (US)**. Комментарии в коде — английские. Общение со мной — русский.

Цель первой версии: **визуально законченный продукт + реально работающая регистрация.**
Реальной обработки изображений НЕТ — везде честный demo/mock UI.

## Позиционирование: чего не делаем в текстах

- AI **не является** основой позиционирования. Запрещённые формулировки: `AI-powered`, `Generate with AI`, `Magic`, `Powered by AI`, `Smart AI`.
- Продаём экономию времени и удобство, а не технологию.
- Никаких `Contact Sales`, enterprise, team, API — это B2C/prosumer продукт.

## Дизайн-система

Спокойный, дорогой, профессиональный американский SaaS.
**Утверждённый макет главной — `design-ref/filekit-home.html`.** Он источник правды по цветам, типографике, отступам и стилю редактора: открой его перед любой вёрсткой и не отклоняйся.

**Палитра** (single accent, без тем и dark mode в v1):

| Роль | Значение |
|---|---|
| Canvas | `#FFFFFF` |
| Surface | `#FAFAFA` |
| Ink (заголовки) | `#0F0F10` |
| Body text | `#52525B` |
| Muted text | `#8B8B93` |
| Border | `#E4E4E7` (1px) |
| Primary button | `#111111` → hover `#000000`, текст белый |
| Accent (единственный) | `#15803D`, tint `#F0FDF4` |

Accent используется только для: галочек в списках, бейджа «Most Popular», активного инструмента, success-состояний.

**Типографика:** Inter (или Geist). Заголовки — weight 500/600, `letter-spacing: -0.02em`. Никакого 800/black.
H1 `clamp(40px, 5vw, 60px)` / line-height 1.05. H2 `32–40px`. Body `16–17px / 1.6`. Текстовые блоки — не шире `68ch`.

**Геометрия:** контейнер `max-w-[1200px]`, паддинги секций `py-20 md:py-28`, радиусы: карточки `12px`, контролы `8px`.
Тени: либо нет, либо `0 1px 2px rgba(0,0,0,.04)`. Разделение элементов — границами, не тенями.

**Запрещено (иначе сайт выглядит «сгенерированным»):**
градиенты (кроме одного едва заметного нейтрального в hero), фиолетово-синий neon, glassmorphism, glow, светящиеся сферы,
абстрактные blobs, шаблонные «AI-иллюстрации», эмодзи в UI, более 3 размеров шрифта на экран, стены текста, десятки секций на главной.

**Логотипы маркетплейсов:** только текстовые wordmark-и в нейтральном сером (`#8B8B93`), без фирменных цветов и без скачанных SVG брендов.

## Архитектура, важные решения

- `lib/brand.ts` — единственное место с названием, доменом, тэглайном. Ребрендинг = правка одного файла.
- `lib/tools.ts` — единственный источник правды по 10 инструментам (id, name, slug, icon, one-liner, token cost). Из него строятся: сетка на главной, `/tools`, левая колонка редактора, расчёт стоимости.
- `lib/plans.ts`, `lib/token-packs.ts` — тарифы и пакеты токенов данными, не в JSX.
- `lib/billing/` — абстракция оплаты: `types.ts` (интерфейс `BillingProvider`), `mock.ts` (текущая реализация), `index.ts` (экспорт активного провайдера). Подключение Stripe позже = новый файл + смена экспорта, **без переделки UI**.
- `components/editor/EditorPreview.tsx` — один компонент редактора, используется и в hero на главной (в рамке браузера, неинтерактивный), и на `/editor` (интерактивный demo). Не рисуем редактор дважды.
- Все секреты — только через env. Есть `.env.example`. Ключи в коде — никогда.
